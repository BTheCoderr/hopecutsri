# Hope Cuts RI

Rhode Island nonprofit. The barber chair as a place for connection, encouragement, and hope.

## Tech Stack

**100% Next.js 14 + TypeScript.** No HTML files. All pages are React components (`.tsx`). The only "HTML" in the project is the root `<html>` and `<body>` tags that Next.js requires—every web framework needs that. You write TypeScript/JSX; Next.js handles the rest.

## Run Locally

```bash
npm install
npm run dev
```

[http://localhost:3000](http://localhost:3000)

## Deploy on Netlify

Connect the repo. Netlify auto-detects Next.js.
